Local work and Git history
-------------------------
git-workspaces.json records 44 Git working directories, their HEADs, local refs,
branch names, original status and deletions. Fifteen had uncommitted changes.
The backup commit preserves all 48 distinct recorded historical tips through its
parents. Extra parents retain object history only; their code was not merged into
the root source tree. Detached review HEADs are recorded too.

working-trees/<directory>/ contains:
- working-tree.patch: binary-capable diff from that directory's recorded HEAD.
- index.patch: original staged diff from HEAD, normally empty here.
- files/: exact bytes of changed and untracked files, including original line endings.

To restore one old workspace, create a NEW checkout/worktree at its recorded HEAD,
apply working-tree.patch if nonempty, then overlay files/ and honor deleted paths
from git-workspaces.json. Applying index.patch with git apply --cached restores
the original staging state. Use the fresh checkout, not an active development tree.
The fifteen worktree patches were checked with git apply --cached --check against
their recorded base trees. file-checksums.json records SHA256 for all 441 copied
files, including small standalone evidence and non-Git staging directories.
workspace-backup/.gitattributes disables line-ending conversion for these records.
