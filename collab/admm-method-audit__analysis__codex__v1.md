## 1. 先定义物理模型，再讨论 ADMM

每步冻结 q、接触集合、J、R 与参考加速度，当前 CPU 声明的模型是：

```
A = J H^-1 J^T
Q = A + R
c = a_ref - J a_smooth
min_{f in K}  0.5 f^T Q f - c^T f
K: fn >= 0, ||ft|| <= mu*fn  （此处只讨论 condim3）
```

这是带锥约束的凸二次目标问题；严格说圆锥版本是锥优化问题，不是只有线性约束的经典 QP。
H 正定使 A 半正定；若 Q 正定则该步最优力唯一。**该步最优解唯一不等于整个仿真存在唯一稳定平衡**，
更不等于碰撞几何、时间积分、真实材料与耗散都正确。R、a_ref、K 改变物理模型；ADMM 只是求解它。

GPU 用冲量 p=dt*f。冻结相同 J、H、R 时，正确对应是 Qp=dt*c；
代码使用 `dt*a_ref - (v_free-v_current)`，在 `v_free-v_current=dt*J*a_smooth` 下与 CPU 相容。
这种力/冲量换算本身不是“有损往返”；差异应检查模型、离散式、近似和收敛。旧 ADMM 已退役，
旧文档把所有往返统称信息丢失的表述不构成当前路径的定量根因证明。

## 2. 分裂如何求解，以及保证从哪里来

令 z 是满足接触约束的力副本，u 是缩放对偶变量，使用 f=z 分裂：

```
(Q + rho*I) f_next = c + rho*(z-u)
z_next = P_K(f_next+u)
u_next = u + f_next-z_next
```

第一步处理全局关节/多接触耦合；第二步按接触独立投影；第三步协调两份变量。
rho 是算法罚参数，R 是目标函数中的柔顺项，两者不能互相替代。收敛时 rho 的影响应消失，R 保留。
当前 rho*I 分裂要求 **欧氏** P_K；若改成矩阵罚项/变量预条件，投影度量与对偶缩放也必须一起改变。

标准凸 ADMM 的理论前提包括闭凸子问题、存在鞍点、子问题求解满足要求等；常见定理针对固定 rho。
残差平衡是一种有用的自适应策略，不保证任意质量/尺度组合都在固定预算内高精度收敛。
我们的数值分析针对上述三步本身，不把不准确投影得到的固定点视作原问题的最优解。

## 3. 原生局限性：尺度、精度、代价、时变接触

**尺度与 rho。** 单法向、非负约束不活跃且冷启动时，z=f、u=0。记标量 Q=q_c>0：

`e_(k+1) = rho/(q_c+rho) * e_k`。

固定 d 时 `q_c=1/(mass*d)`；重物体使 q_c 相对 rho 变小，因此收敛慢。
历史“重物体导致 R 更主导”的解释不正确：**R/A=(1-d)/d 不变**。
当非负约束活跃在零点时，对偶误差的收缩规律不同，单纯把 rho 调小也不是通用解。
统一尺度、基于谱/残差调整和必要的预条件值得评估，但必须保持同一物理目标及正确投影。

**精度与有限预算。** 实时预算允许截断，截断解就可能有显著模型误差。不能把“跑了30/50次”当收敛证据。
可行性、最优性、时间轨迹精度需分别测。ADMM 通常较快达到中等精度，严格精度可能需要很多迭代。

**计算代价。** m 条接触行的稠密因子分解通常 O(m^3)、存储 O(m^2)，理想三角回代每次 O(m^2)。
CPU 虽缓存 Cholesky，却每次用两次 `np.linalg.solve` 处理三角阵；该接口调用通用 gesv，
没有显式利用三角回代。可换专用三角求解，但本轮没有性能基准，不能承诺加速倍数。
当前 Warp ADMM 是每环境一个线程内的标量 Cholesky/循环；环境间批量并行，未实现历史路线图中的 tensor-core ADMM。
自适应 rho 会触发重新分解，节省迭代数不必然节省总时间。

**接触时变。** 每帧是新优化问题，接触对象、顺序、法向、切向基、dt 都可能变。
warmstart 是启发式初值，不是动力学记忆变量；正确缓存映射有利于有限预算，但不能代替收敛验证。

## 4. 各项修正：目的、依据与当前实现

| 修正 | 有依据的目的 | 实现与局限 |
|---|---|---|
| joint-space A | 保留关节与跨接触惯性耦合 | CPU/GPU 已采用；构造正确仍需独立 J/H 验证。CPU contact pipeline/cache 与 ADMM 内部仍重复部分动力学计算 |
| per-row R=(1-d)/d*diag(A) | 按有效逆惯性缩放柔顺性，缓和冗余约束与力分配 | CPU 正确构造；R 不是纯预条件，会改变最终力。GPU 从含 PGS 正则化的 W_diag 构造 R，已确认与意图不同 |
| solref/solimp | 定义穿透恢复、速度阻尼与距离相关阻抗 | CPU/GPU 有对应公式；tc>=2dt 是稳定性保护启发，不是任意耦合场景的积分稳定证明，也不是直接材料标定 |
| 正确锥投影 | 精确解 ADMM 的 z 子问题 | 当前 CPU/GPU 固定法向后截断切向；不是所需欧氏锥投影，已由含 per-row R 的解析反例确认 |
| 自适应 rho | 缓解固定 rho 与矩阵尺度失配 | CPU 在单次 solve 内 rescale u 正确；GPU 固定 rho=1、默认30次；CPU 跨 solve 丢失最终 rho 的尺度信息 |
| warmstart | 用上次解减少迭代 | CPU 仅看总行数，GPU 仅看活动接触数；均未按接触身份/基变换复用。CPU 空接触早退不清空旧 warm cache；adapter 无接触也跳过 inner.solve |
| primal+dual stopping | 同时检查共识与迭代变化 | CPU 两项均检查，但共享一个绝对1e-8且不返回残差/耗尽状态；GPU 固定预算无停止判断。力/冲量/角向行不能无尺度地共用公差 |
| Cholesky 数值保护 | 应对分解的数值问题 | CPU 失败后加1e-6 I；GPU 截断小于1e-4的 pivot。若触发会扰动实际线性系统，不只是无害的算法 rho；本轮未测触发频率 |

R 的正定作用有条件：对当前未实现的 condim4 角向零 J 行，A_ii=R_ii=0，实测 Q 有零特征值。
rho*I 使该次线性子问题可解，并不能证明原目标严格凸或角向接触能力已实现。
per-row R 也不普遍改善条件数：A=diag(1,10^6)、d=.9 时，Q=A/.9 的条件数仍为10^6。

对单个解耦方向，d 可解释为参考/自由加速度的插值比例；耦合多接触只近似成立。
按本仓库公式，孤立法向静态穿透计算为 .367182 mm，而现有四足四接触耦合参考为 .250836 mm。
所以“穿透与结构无关”“per-row 一定比 MuJoCo 更物理正确”“增加 R 自动保证时间仿真稳定”均过强。
原论文还包含正则化下限及摩擦维度调整；本项目 per-row 选择有渊源，但不是论文所有条件的完整实现。

## 5. 新实测：有限预算与缓存

所有 CPU 标量反例使用 condim1，排除了已知摩擦投影缺陷的干扰；无约束法向加速度为 ±1 m/s²。
Trace 子类只计数/记录生产分解和投影调用，未替换求解算法。完整脚本/结果在 admm-method-evidence。

| 场景 | 设置 | 结果 | 判断 |
|---|---|---|---|
| 50kg 单法向 | d=.9、固定rho1、50次 | 力30.004995 N，解析45 N；误差33.3222% | 与标量收缩公式精确一致，是有限迭代不足 |
| 同上 | 自适应rho，上限50 | 13次，力44.999999819 N | 自适应确有收益，但进行了13次分解 |
| 1000kg 单法向 | 固定rho1、50次 | 48.61022 N，解析900 N；误差94.5989% | 统一迭代数无统一精度 |
| 同上 | 自适应rho | 18次，899.999999888 N | 此简单场景修正有效，不代表所有多接触问题 |
| CPU 分离方向 | 一次/五次迭代 | 返回法向力 -.473684 / -.000291232 N；投影副本为0 | CPU 返回未投影 f；有限预算可违反单边接触。默认50预算本例8次退出，残差约1.44e-9 N |
| 重复同一零力问题 | 前次rho512，下次重置1，u原样复用 | 缓存真实对偶y约-1，却被解释为-.001953125；重复需10次 | 不再是复用前次同一对偶解。诊断中仅换算u后1次完成 |
| 两独立接触交换顺序 | 行数仍为2，下一步只做1次 | 应为[9,.9]N，得到[5.16316,4.73684]N | 依行数复用错位；诊断中仅重排缓存得到[9,.9] |

上面两种 warmstart 问题是**缓存语义/有限预算质量问题**。标准 ADMM 可以从任意初值收敛，
因此不能据此宣称它们必然改变完全收敛的最优解。重排/换算只发生于诊断中的对照副本，生产未修复。
CPU 输出 f 与 GPU 输出投影 z 的策略也不同；改为返回可行副本仍不能保证最优，需同时报告求解质量。

真实 H200 的单球新接触（dt=.2ms，初始穿透10μm，冷启动）进一步测得：

| 质量 | GPU30次相对冲量误差 | GPU300次误差 |
|---:|---:|---:|
| .1kg | 5.0e-9 | 5.0e-9 |
| 1kg | 3.15e-8 | 3.15e-8 |
| 50kg | 51.7180% | .13698% |
| 1000kg | 96.7231% | 71.6648% |

参考直接使用**该次实际 GPU 的 W、R、rhs**：单法向 `p*=rhs/(W_nn+R_nn)`，不是强行套 CPU 参数。
因而这项测量隔离了迭代不足，未与 GPU R 构造差异混为一谈。首次接触没有历史解可供 warmstart；
后续帧效果可能改善，但不能借后续落地稳定掩盖初次响应误差。本轮未宣称这些比例适用于所有机器人轨迹。

前次含 per-row R 的36组摩擦实验也保留：改变 d/rho/adaptive，primal residual均<1e-11，
但目标差为 .125 至2.2275。三变量球面反例 d=.9、A=diag(1,3.5,3.5)、rhs=[1,8,0]、mu1，
输出[.9,.9,0]，解析最优[1.8,1.8,0]。这是**子问题实现不正确**，与上述有限迭代不足是不同问题。

## 6. 建议的验证与修正顺序（尚非实施批准）

1. 冻结当前目标 Q、c、K、单位和 CPU力/GPU冲量对应关系；保留 per-row R，并明确真实材料参数仍未标定。
2. 先用解析小问题验证投影/最优性，修复子问题与 GPU R 来源；加迭代或调rho不能修好错误投影。
   对当前已声明模型恢复正确投影属于一致性修复，但会改变滑动时法向耦合，需显式评估行为变化。
3. 明确有限预算输出、可行性与耗尽状态；建立按物理尺度的绝对+相对残差。KKT检查须含锥法锥条件，
   或使用独立正确投影的自然残差；只检查 f≈z 和 z 不再变化会漏掉当前错误固定点。
4. 定义缓存接触身份、点/基变化、接触消失、rho缩放、dt变化规则；再评估warmstart收益。
   加入同数量换接触、顺序交换、法向旋转、重复solve及离开后重新接触等测试。
5. 在相同模型与误差目标下比较固定rho/自适应rho/尺度化、三角回代/分解复用，以及必要的高精度精化。
   记录因子分解次数、总耗时、残差和冲量/速度误差；不凭算法名称决定ADMM或Newton谁更好。
6. 再验证步长收敛、接触建立/解除、滑动/滚动、耦合负载和真实材料。几何漏检与积分误差要独立诊断。

当前没有依据废弃 ADMM 或删除 R，也没有依据宣称现有 ADMM 已正确解出其全部声明模型。
最优先工作是恢复模型与子问题的一致性，并让求解质量可观测；性能和更换算法在此基础上评估。
